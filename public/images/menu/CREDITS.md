free, irrevocable licence to use photos for commercial purposes without permission or attribution.
Attribution is not legally required, but Unsplash's API guidelines ask for it and it costs us
nothing — so the photographers are credited here.

All images were downloaded, cropped to 1200×520 and converted to WebP (~73 KB each,

## Replacing these with the resort's own photos

These are stock. Real photos of the resort's actual dishes would be better — see the resort's
Instagram/Facebook. To swap one, just overwrite the file here at the same size (1200×520) and
filename; nothing in the code needs to change. Alt text lives in `src/lib/menu.ts`.
