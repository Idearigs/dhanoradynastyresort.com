# Dish image credits

Per-dish photos in this folder are from [Unsplash](https://unsplash.com), free for commercial use.
Each is cropped to 400x300 and saved as WebP (~20 KB each, 1.2 MB for all 60) and lazy-loaded,
so only the open menu category downloads any of them.

## Dishes WITHOUT a photo (they fall back to the category banner)

Unsplash has no usable photo of these, and a wrong photo is worse than a generic one:

- **Milk Rice (kiribath)** - no results
- **String Hoppers (idiyappam)** - no results
- **Chicken Devilled** - no results
- **Prawn Devilled** - no results

## Replacing with the resort's own photos

Drop a 400x300 WebP over the matching filename - no code change needed. To ADD a photo for one
of the six dishes above, save it as the slugified name (e.g. `milk-rice.webp`) and add that slug
to `DISH_IMAGES` in `src/lib/menu.ts`.
